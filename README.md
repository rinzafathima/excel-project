# 📊 Employee Data Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing employee data using **Microsoft Excel** to identify important workforce trends and generate meaningful business insights. The dataset contains information about employees, including age, department, managerial status, joining date, experience, and salary.

The project involves **data cleaning, transformation, analysis, and visualization** to create an interactive dashboard that helps understand employee distribution, salary patterns, experience levels, and other key workforce metrics.

---

## 🎯 Objectives

* Analyze employee demographics and workforce distribution.
* Understand salary patterns across different departments.
* Analyze employee experience and age groups.
* Compare managers and non-managers.
* Identify departments with higher employee counts and salary levels.
* Create meaningful KPIs and visualizations.
* Develop an easy-to-understand Excel dashboard for decision-making.

---

## 📂 Dataset

The dataset contains **500 employee records** with the following fields:

| Column      | Description                                   |
| ----------- | --------------------------------------------- |
| Employee ID | Unique identification number of each employee |
| Age         | Age of the employee                           |
| Department  | Employee's department                         |
| Is Manager  | Indicates whether the employee is a manager   |
| Join Date   | Date the employee joined the organization     |
| Experience  | Years of professional experience              |
| Salary      | Employee's salary                             |

The final dashboard provides an interactive view of the employee data, including:

* Average Experience

* Salary Analysis by Department
* Employee Distribution by Age/Experience
* Manager vs Non-Manager Analysis

## 🔍 Key Analysis Areas

### Employee Analysis

Analysis of employee distribution based on department, age, experience, and managerial status.

Comparison of average and total salary across departments and employee categories.

### Experience Analysis

Analysis of employee experience levels to understand the workforce structure.

### Managerial Analysis

Comparison between managers and non-managers to understand organizational hierarchy.
